# Changelog

## 1.0.0

- First release of The Boring Camera Card as a plain dashboard card (HACS category *Dashboard*).
- Live view through go2rtc, push-to-talk, recordings strip, person / animal / vehicle markers, face avatars.
- Setup through the card's own form in the dashboard editor — no YAML needed.
- Step-by-step setup guide with images in the README.
